## 一、项目总览

### 1.1 项目定位

面向镇街网格化治理的"**发现上报 → 智能派单 → 现场处置 → 复核核查 → 督办预警 → 归档**"全流程闭环平台,覆盖事件工单、网格人房治理、巡查防控、应急调度、无人机/视频智能应用、智慧党建、考核研判、电子台账等场景。

### 1.2 四大应用端

| 端 | 目录 | 技术栈 | 端口 | 使用者 | 生产地址 |
|---|---|---|---|---|---|
| 后端 API | `backend/` | Spring Boot 3.3 / Java 17 / JdbcTemplate / Flyway | 8080 | — | 10081→8080 |
| Web 管理端 | `web/` | Vue 3 + TypeScript + Vite | 5175 | 管理员/调度员 | https://drone.kfktec.cn:8443/ |
| 移动端小程序 | `h5/` | Vue 3 + uni-app(编译微信小程序) | 5174 | 网格员 + 居民 | 小程序包 `/h5/`(网页版已弃维护) |
| 居民端(废弃) | `mp/` | Vue 3 + Vite | 5176 | 居民 | 已被 h5 居民端替代,保留代码 |

依赖服务:MySQL(zhsq)、Redis、MongoDB(alarm_dgcp)、MinIO(dgcp-oa)、无人机平台(9085)、高德地图。

## 四、后端服务功能清单(30 模块 / 68 Controller)

### 4.1 认证权限(auth)

- **双端登录**:Web/居民 `POST /api/auth/login`,网格员 `POST /api/h5/auth/login`(clientType 隔离),返回 JWT(7 天)
- **当前用户/登出**:`/auth/me`、`/auth/logout`、`/h5/auth/me`
- **RBAC 权限**:用户→角色→权限,`API_*` 接口权限(后端 @RequirePermission 校验)+ `menu:*` 菜单权限(前端导航);Web/H5 独立权限面

### 4.2 事件闭环(event + workorder + process + audit)

- **事件管理**:创建/列表/详情/热力图/地图点位/统计;紧急程度三色(绿/黄/红);生命周期时间轴;附件
- **事件处置**:派单(单条/批量)、标记误报、批量删除/审核、关闭/重开/归档、更新紧急度
- **自动升级**:GREEN 超 24h→YELLOW,超 48h→RED(定时任务+手动触发接口)
- **多源上报**:网格员上报、居民随手拍(免认证 public-report)、物业上报、12345 热线导入、三方告警回调
- **群众评价**:1-5 星 + 统计
- **工单中心**:事件派单生成工单;处理节点流转(接单→到场→处理→提交);确认/驳回关闭;批量删除;导出
- **智能派单规则**:`biz_dispatch_rule` 事件类型→角色映射 + 角色内待办最少负载均衡推荐 + 一键智能派单
- **审核中心**:发起审核/审核详情;流程模板 CRUD;审批通过/驳回;流程实例节点追踪
- **工单自动处置**:48h 未接单自动关闭;72h 未处置升级紧急度;超 24h 未完成站内通知(每小时)

### 4.3 网格治理(community + ledger + resident)

- **网格管理**:三级网格(社区→大网格→小网格)树形 CRUD;边界形状
- **实有人口库**:人口 CRUD、按网格筛选、Excel 批量导入(预览+执行)
- **房屋/出租屋库**:楼栋 CRUD、导入
- **场所资源库**:场所 CRUD、导入;商户/摊贩/辖区/违禁区域 CRUD(Web+H5 双端接口)
- **组织人员**:网格员 CRUD、从系统用户同步
- **居民上报**:列表/详情/按查询码查/处理
- **居民报修**:报修申请、Web 报修管理、H5 提交
- **政策资源**:CRUD + 匹配适用人群
- **电子台账**:6 类台账(事件/人口/房屋/商户/巡查/安全)模板 CRUD + 数据查询 + 一键导出 Excel(中文表头+枚举值中文翻译+筛选透传)
- **巡查**:任务生成(每周一 01:00 自动+手动)、任务完成(H5)、打卡记录(clientRequestId 幂等)、轨迹数据(GIS 图层)
- **趋势预判预警**:同类型同网格 7 天≥3 起 / 同地点 7 天≥2 次自动生成预警(每 30 分钟扫描)+ 处理闭环 + 站内通知

### 4.4 巡查防控(safety + parking + vehicle + emergency)

- **安全检查**:检查记录 CRUD、整改状态流转、超期未整改标记、统计
- **停车管理**:车位统计/列表/实时状态/状态更新;违停记录/统计/告警/派单/关联工单
- **车辆轨迹追踪**:进出记录(ENTER/EXIT/MOVE)+ 单车轨迹 + 统计 + 演示数据生成;真实车牌识别相机推送接入预留
- **应急调度(三级)**:一级(社区干部)/二级(多部门联动)/三级(区级上报)应急指令;多网格一键联合调度;接收回执反馈闭环;站内通知联动;Web/H5/居民端三端接口(`/emergency/dispatches`、`/h5/emergency`、`/mp/emergency/dispatches`)

### 4.5 智能应用(drone + video + integration)

- **无人机管理**:设备列表、任务创建/暂停恢复/返航、航线管理(航点详情)、媒体文件列表/下载、摄像头模式/录像控制、喊话器(上传/播放/停止/音量)、工作空间、HLS/FLV 实时流代理、AI 模型绑定(通义千问 qwen)
- **无人机看板**:总览/设备/任务/航线/AI 告警
- **视频监控**:监控点位列表、视频流地址、外部视频源
- **信息互通**:外部系统 CRUD、手动同步、同步日志、连通性检查、统计;第三方告警回调入口(免认证)
- **蚊媒监测**:蚊媒消杀记录 + 蚊媒设备(捕蚊器)管理 + 设备数据上报回调(MQTT/HTTP)+ 定时拉取设备数据

### 4.6 党建志愿(party)

- **党建**:党员管理、党员联户+走访记录、三会一课、党员量化考核(月度自动生成)、议事协商(议题/投票/关闭)、党员任务(创建/接受/完成)、政策推送
- **志愿服务**:志愿活动、报名、积分与流水;H5 志愿端接口
- **政策资源**:党建政策资源列表

### 4.7 数据决策(report + assessment)

- **数据报表**:区域汇总报告 + 导出
- **看板**:总览、网格统计、台账统计、大屏数据、网格排名、月度汇总
- **考核研判**:总览统计、网格员效能、事件处置时效、群众评价统计、月度报告、巡查覆盖率、整改率、趋势预警

### 4.8 通知消息(notification + messaging)

- **站内通知**:列表/未读数/已读/全部已读/删除;H5 端接口;自动通知(派单/工单超期/趋势预警/应急指令/巡查提醒)
- **站内消息**:会话列表/聊天记录/已读;WebSocket(STOMP)实时推送(注:H5 聊天入口暂隐藏)

### 4.9 系统支撑(system + audit + oss + registration + biz)

- **系统管理**:用户(CRUD/状态/角色/密码)、角色(CRUD/权限分配)、权限树、菜单树 CRUD
- **审计日志**:数据变更审计(新增/修改/删除)、变更历史、差异对比、回滚预览、数据回滚
- **文件上传**:MinIO 上传/删除/下载代理/访问前缀;媒体上传(扁平存储 + 兼容日期子目录存量)
- **居民注册**:提交申请→审核通过/驳回
- **导出/导入**:事件/工单 PDF、台账 Excel、Excel 批量导入(人口/房屋/场所)
- **测试工具**:仅 `APP_TEST_ENABLED=true` 启用(建测试账号/修迁移/权限初始化)

### 6.4 离线采集机制(B2/R07)

- **离线队列** `h5/src/utils/offlineQueue.ts`:双端存储(小程序 uni storage / H5 localStorage);断网自动入队
- **自动同步**:网络恢复监听 + 30 秒定时重试 + App 启动同步
- **错误分级**:网络错误保留重试(超 5 次标失败);业务错误直接标失败不自动重试;支持手动重试
- **幂等保障**:事件上报 fixed externalEventId;巡查打卡 clientRequestId 后端唯一键去重
- **单测**:7 个 vitest 用例(入队/flush/错误分级/重试/清理)

## 七、核心机制

### 7.1 定时任务(7 个)

| 任务 | 频率 | 功能 |
|---|---|---|
| EventAutoEscalationTask | 每 30 分钟 | 事件紧急度自动升级(24h/48h) |
| TrendAlertTask | 每 30 分钟 | 趋势预判预警扫描(≥3 起/≥2 次) |
| WorkOrderAutoHandleTask | 每小时 | 工单 48h 未接自动关、72h 升级 |
| NotificationScheduler | 每小时 | 超 24h 工单提醒通知 |
| PatrolTaskScheduler | 每周一 01:00 + 每天 02:00 | 巡查任务生成 + 超期标记 |
| MosquitoDeviceDataTask | 定时 | 蚊媒设备数据拉取 |
| 外部系统同步 | 每 30 分钟 + 每天 03:00 | 外部数据拉取 + 日志清理 |

### 7.2 数据库(Flyway V1-V96)

核心表:`biz_event`(事件)、`biz_work_order`(工单)、`cmn_grid`(三级网格)、`cmn_population/building/place`(人房场)、`cmn_patrol_task/record`(巡查)、`sys_user/role/permission/menu`(RBAC)、`sys_audit_log`(审计)、`sys_notification`(通知)、党建/停车/无人机/台账/评价/消息/注册/外部系统等 80+ 张表。

### 7.3 权限模型

- RBAC:用户→角色→权限;`API_*`(后端接口校验)+ `menu:*`(前端菜单/入口显示)
- Web/H5 独立权限面(clientType 区分);居民 PUBLIC 角色只读

### 7.4 通用能力

- **审计**:AOP 拦截全部写操作,记录新旧值,支持差异对比与回滚
- **文件**:MinIO 对象存储;媒体文件扁平存储;三端定位高德 IP 兜底
- **通知**:站内通知全覆盖(派单/超期/预警/应急/巡查);WebSocket 聊天
- **导出**:Excel(POI)台账/工单、PDF、CSV 报表;中文表头+枚举翻译
