## 四、数据流追踪

### 核心数据流

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           事件数据流                                      │
│                                                                         │
│  小程序/Web ──→ public-report ──→ MySQL (biz_event)                     │
│                     │                    │                               │
│                     └──→ MongoDB ◄──────┘                               │
│                          │                                              │
│                          ▼                                              │
│                    事件列表查询                                          │
│                    (queryEvents)                                        │
│                          │                                              │
│              ┌───────────┼───────────┐                                  │
│              ▼           ▼           ▼                                  │
│          Web 列表    H5 列表    统计看板                                 │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│                           工单数据流                                      │
│                                                                         │
│  Web 派单 ──→ biz_work_order ──→ biz_process_instance                   │
│                  │                      │                                │
│                  │                      ├──→ biz_process_instance_node   │
│                  │                      └──→ biz_process_action_record  │
│                  │                                                       │
│                  ▼                                                       │
│              H5 接单 ──→ H5 处置 ──→ 上传附件 ──→ biz_media_file        │
│                  │           │                                          │
│                  │           └──→ 提交结果                              │
│                  │                                                       │
│                  ▼                                                       │
│              Web 复核 ──→ 确认关闭 ──→ 事件 CLOSED                      │
│                           │                                             │
│                           └──→ 驳回 ──→ 退回处理中                       │
└─────────────────────────────────────────────────────────────────────────┘
```

### 数据一致性检查

| 检查项 | 状态 | 说明 |
|--------|------|------|
| MySQL ↔ MongoDB 同步 | ⚠️ | 仅事件上报同步，其他模块未同步 |
| 事件状态 ↔ 工单状态 | ⚠️ | 存在状态不一致场景 |
| 工单状态 ↔ 流程实例状态 | ⚠️ | rejectClose 未重置流程状态 |
| 缓存 ↔ 数据库 | ✅ | Redis 仅用于会话，无缓存一致性问题 |

## 六、技术债务清单

| 债务 | 影响 | 优先级 | 状态 |
|------|------|--------|------|
| MongoDB/MySQL 双数据源 | 数据不一致风险 | 高 | ✅ 已修复同步机制 |
| CONTINUE_PROCESSING 无限循环 | 工单无法完成 | 高 | ✅ 已修复 |
| confirmClose 状态检查 | 重复关闭 | 高 | ✅ 已修复 |
| rejectClose NPE | 系统崩溃 | 高 | ✅ 已修复 |
| 硬编码操作人"系统" | 审计追踪缺失 | 中 | ⏳ 待处理 |
| 缺少单元测试 | 代码质量无法保证 | 中 | ⏳ 待处理 |
| 缺少接口限流 | 可能被恶意调用 | 低 | ⏳ 待处理 |
| 缺少操作日志 | 无法追溯 | 低 | ⏳ 待处理 |
