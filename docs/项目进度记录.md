## 五、已知待优化项

### 高优先级
- [ ] WorkOrderServiceImpl CONTINUE_PROCESSING 分支无限循环风险
- [ ] confirmClose 不检查事件当前状态
- [ ] rejectClose 不重置流程实例状态
- [ ] handle() 不检查工单状态
- [ ] EventServiceImpl autoEscalateUrgency NPE 风险

### 中优先级
- [ ] GlobalExceptionHandler 缺少多种异常处理器
- [ ] 操作人审计字段硬编码为"系统"
- [ ] 未验证的第三方回调仍被处理
- [ ] BearerTokenAuthenticationFilter 支持 query param 传 token

### 低优先级
- [ ] 外部系统同步接入真实 API（当前模拟数据）
- [ ] 巡查任务定时自动生成（当前手动触发）
- [ ] 安全响应头配置（X-Frame-Options 等）

## 六、部署说明

### 依赖服务

| 服务 | 默认地址 | 说明 |
|------|---------|------|
| MySQL | 127.0.0.1:3306 | 业务数据库，库名 `zhsq` |
| MongoDB | 127.0.0.1:27017 | 告警事件存储 |
| Redis | 127.0.0.1:6379 | 缓存/会话，database=7 |
| MinIO | 127.0.0.1:9009 | 文件对象存储，bucket=`dgcp-oa` |

### 启动命令

```bash
# 后端
cd backend && ./mvnw spring-boot:run

# Web 管理端
cd web-v2 && npx pnpm dev --host 0.0.0.0 --port 5175

# H5 移动端
cd h5 && npx pnpm dev --host 0.0.0.0 --port 5174

# 小程序（居民端）
cd mp_mysql_test && npx pnpm dev --host 0.0.0.0 --port 5176
```
