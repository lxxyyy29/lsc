## 六、部署说明

### 依赖服务

| 服务 | 默认地址 | 说明 |
|------|---------|------|
| MySQL | 127.0.0.1:3306 | 业务数据库，库名 `zhsq` |
| MongoDB | 127.0.0.1:27017 | 告警事件存储 |
| Redis | 127.0.0.1:6379 | 缓存/会话，database=7（Docker 部署为 0） |
| MinIO | 127.0.0.1:9009 | 文件对象存储，bucket=`dgcp-oa` |

生产环境使用 `docker/` 目录 docker-compose 部署，容器：changping-backend(10081)、changping-web(8888)、changping-h5(10082)、changping-mp(10083) 及 MySQL/Redis/MongoDB/MinIO。

### 启动命令

```bash
# 后端
cd backend && ./mvnw spring-boot:run

# Web 管理端
cd web && npx pnpm dev --host 0.0.0.0 --port 5175

# H5 移动端
cd h5 && npx pnpm dev --host 0.0.0.0 --port 5174

# 小程序（居民端）
cd mp && npx pnpm dev --host 0.0.0.0 --port 5176
```
