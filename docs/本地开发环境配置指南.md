## 三、后端启动

### 3.1 IDEA 运行配置

- **Main class**: `com.changping.platform.Application`
- **JRE**: JDK 17
- **VM options**:
  ```
  -Dspring.flyway.baseline-on-migrate=true -Dspring.flyway.baseline-version=30
  ```

> ⚠️ **Flyway baseline 必加**：基线版本 30（V30 是占位迁移，V1-V29 的表由 init-db.sql 提供）。

```bash
java -jar target/platform-0.0.1-SNAPSHOT.jar --spring.flyway.baseline-on-migrate=true --spring.flyway.baseline-version=30
```

### 3.3 验证启动成功

```

Started Application in xx seconds
```

测试：`http://localhost:8080/api/auth/hello` 返回 `{"success":false,"code":"AUTH_TOKEN_REQUIRED",...}` 即正常。

```bash
cd h5 && npx pnpm dev

# MP 小程序（端口 5176）
cd mp && npx pnpm dev --host 0.0.0.0 --port 5176
```

### 4.3 web 端代理配置

`web/vite.config.ts` 中 `/api` 代理指向本地后端：

```ts
proxy: {
  '/api': {
    target: 'http://127.0.0.1:8080',  // 本地开发用 8080，生产是 9072
    changeOrigin: true,
    ws: true,
  }
}
```

> ⚠️ 提交前改回 9072，或保持本地不改（以仓库为准）。

## 五、菜单权限修复（新环境必做）

由于 `init-db.sql` 基线缺少部分 `web:menu:*` 权限记录，启动后导航栏会缺失菜单。执行以下 SQL 补齐：

```sql
-- 1. 插入缺失的 web:menu 权限
INSERT IGNORE INTO sys_permission (permission_code, permission_name, permission_type, client_type, path, sort_order, status, remark, created_at, updated_at) VALUES
('web:menu:big-screen', '综合监管大屏', 'MENU', 'WEB', '/big-screen', 202, 'ACTIVE', 'Web菜单-首页概览', NOW(), NOW()),
('web:menu:events', '事件闭环处置', 'MENU', 'WEB', '/events', 203, 'ACTIVE', 'Web菜单-事件工单', NOW(), NOW()),
('web:menu:work-orders', '已完成工单', 'MENU', 'WEB', '/work-orders', 204, 'ACTIVE', 'Web菜单-事件工单', NOW(), NOW()),
('web:menu:audits', '事件审核', 'MENU', 'WEB', '/audits', 205, 'ACTIVE', 'Web菜单-事件工单', NOW(), NOW()),
('web:menu:grid-manage', '网格管理', 'MENU', 'WEB', '/grid-manage', 208, 'ACTIVE', 'Web菜单-网格治理', NOW(), NOW()),
('web:menu:trend-alerts', '趋势预判预警', 'MENU', 'WEB', '/trend-alerts', 225, 'ACTIVE', 'Web菜单-数据决策', NOW(), NOW()),
('web:menu:audit-logs', '审计日志', 'MENU', 'WEB', '/audit-logs', 226, 'ACTIVE', 'Web菜单-数据决策', NOW(), NOW()),
('web:menu:system-roles', '角色管理', 'MENU', 'WEB', '/system-roles', 231, 'ACTIVE', 'Web菜单-系统设置', NOW(), NOW());

-- 2. 给 SUPER_ADMIN 角色分配这些权限
INSERT IGNORE INTO sys_role_permission (role_id, permission_id, created_at, updated_at)
SELECT r.id, p.id, NOW(), NOW()
FROM sys_permission p
CROSS JOIN sys_role r
WHERE p.permission_code IN ('web:menu:big-screen','web:menu:events','web:menu:work-orders','web:menu:audits','web:menu:grid-manage','web:menu:trend-alerts','web:menu:audit-logs','web:menu:system-roles')
AND r.role_code = 'SUPER_ADMIN';
```
