## 2026-09-11

### 实有人口「户」建模与户主变更关系联动（未提交）

> 背景：反馈两个问题——① 无法把新增人员挂到具体户口下；② 户主变更后其他成员「与户主关系」不跟着变。
> 根因：`cmn_population` 原先没有"户"实体，只有 `address` 字符串 + `relation` 字符串；"户"是查询时按地址临时分组的展示手法，没有户主外键、没有成员归属，因此既无法挂户，也无法在户主变更时推算关系。

#### 一、数据库（Flyway V124）

| 变更 | 说明 |
|---|---|
| 新增 `cmn_household` | 户表：户号 / 地址 / 网格 / `head_population_id`（户主）/ 户籍类型 / 状态 |
| `cmn_population` 新增 `household_id` | 归属户，附 `idx_pop_household_id` 索引 |
| 存量归户 | 按 `网格 + TRIM(地址)` 建户并回填 `household_id`（仅常驻、有地址；流动人口不建户）|
| 指定户主 | 每户取 `relation='户主'` 的成员（多个取最小 id）；无标记的户留待管理端设置 |

#### 二、后端

- 新增 `HouseholdEntity` / `HouseholdVo` / `MemberChangeVo`
- 新增 `HouseholdMapper`、`HouseholdService` / `HouseholdServiceImpl`、`HouseholdController`（`/community/household`，复用 `menu:community:population` 权限）
  - 户 CRUD（删除仅允许空户）、挂成员、移出成员、`change-head`（变更户主）、`change-head/preview`（变更预览）
- 新增 `HouseholdRelationResolver`：关系推算规则（配偶 / 子女 / 父母 / 兄弟姐妹 / 祖孙 / 儿媳女婿），无法推算置「其他」并由前端提示人工核对
  - 锚点关系（新户主相对原户主）优先取入参，其次用新户主当前 `relation` 自动推断
- `PopulationEntity` 增加 `householdId`（另加 `householdAddress`/`householdNo` 非表字段）
- `PopulationMapper`：`search`/`findResidentsByAddresses` JOIN 户表带出户信息；新增 `findByHouseholdId`、`findByHouseholdIds`、`updateRelation`、`updateHousehold`、`clearHousehold`、`syncHouseholdFields`、`countHeads`；`insert`/`update` 写入 `household_id`
- `PopulationServiceImpl`：`tree()` 改为按 `household_id` 分户（未归户回退按地址）；新增/编辑支持挂户并做「一户一主」校验；改为流动人口时自动移出户；删除户主时清空户的户主指向
- `ImportService`：导入常驻人口时按 网格+地址 自动归户（带内存缓存），`户主` 行仅在户无户主时生效

#### 三、Web 前端

- `PopulationView.vue`：新增「新建户」入口与户表单弹窗；人员表单新增「所属户」下拉（选择后带出地址/网格）；新增「变更户主」弹窗（选新户主 → 预览关系重算 → 确认）
- `PopulationCardList.vue`：户卡片新增「新增成员」「变更户主」，成员行新增「移出该户」

#### 四、验证

- `mvnw compile` 通过
- 新增 `HouseholdRelationResolverTest`（7 用例全部通过），覆盖客户举例场景：原户主=张三父亲、张三(儿子)、原户主配偶 → 变更户主为张三后 张三父亲=父亲、张三母亲=母亲、张三妹妹=姐妹
- Web 端未做本机编译（无 node_modules），仅通过编辑器诊断

#### 遗留与建议

- 存量数据若存在「一户多个 relation='户主'」，迁移不自动清理，管理端用 `multipleHeads` 标记提示，需人工用「变更户主」修正
- 关系推算为有限直系规则，再婚/收养/隔代等复杂家庭结构可能落到「其他」，需人工核对

### 结论与注意点

- `/api/resident/**` 仅限 WEB 客户端属**预期设计**：前端账号密码登录为两段式（先试 H5 失败静默 → 再试 WEB），居民走 WEB 登录后 clientType=WEB，互动接口正常
- **微信一键登录需配置** `WECHAT_APPID / WECHAT_APPSECRET` 才能真机联调（生产需确认 `docker/.env` 已配）
- 未覆盖项（需真机/部署环境）：微信开发者工具与真机渲染、8443 nginx 聚合层转发、WebSocket 消息推送、微信环境下的定位
