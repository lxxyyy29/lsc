### 一、功能改动

#### 1. 事件类型 / 上报来源 字典化

- 新增迁移 `V121__dict_event_type.sql`（事件类型字典 `event_type`，8 项中文值，与 `biz_event.event_type` 存量数据一致）

### 结论与注意点

- `/api/resident/**` 仅限 WEB 客户端属**预期设计**：前端账号密码登录为两段式（先试 H5 失败静默 → 再试 WEB），居民走 WEB 登录后 clientType=WEB，互动接口正常
- **微信一键登录需配置** `WECHAT_APPID / WECHAT_APPSECRET` 才能真机联调（生产需确认 `docker/.env` 已配）
- 未覆盖项（需真机/部署环境）：微信开发者工具与真机渲染、8443 nginx 聚合层转发、WebSocket 消息推送、微信环境下的定位
