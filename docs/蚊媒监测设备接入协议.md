# 蚊媒监测设备接入协议

> 适用平台:社区治理数字化平台(爱卫/蚊媒管控模块)
> 更新时间:2026-08-13
> 演示阶段:平台内置模拟数据源(一键生成演示数据 + 每 30 分钟补点),真实设备接入后仅需替换数据源为真实推送,页面与接口不动。

## 1. 接入流程总览

```
蚊媒监测设备(智能捕蚊器/密度监测仪等)
        │  HTTP POST 监测数据(设备无平台账号,接口公开)
        ▼
平台推送接口  POST /api/integrations/mosquito/device-data
        │
        ├── 1. 自动注册设备台账(首次上报建档)
        ├── 2. 超标判定(metricValue > threshold → OVER)
        ├── 3. 去重(同设备+同指标+同采集时间只保留一条)
        └── 4. 刷新在线状态(last_online_at)
        ▼
Web 端"爱卫蚊媒管控 → 检测设备监测"Tab 实时展示
(设备台账 / 趋势曲线 / 超标红点 / 数据明细)
```

## 2. 推送接口协议

### 2.1 请求

| 项 | 值 |
|---|---|
| URL | `POST https://drone.kfktec.cn:8443/api/integrations/mosquito/device-data` |
| Content-Type | `application/json` |
| 鉴权 | 无(设备无平台账号,接口已在 SecurityConfig 白名单放行) |

### 2.2 请求体字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `deviceNo` | ✅ | 设备编号,厂商唯一标识 |
| `metricValue` | ✅ | 指标数值(数字) |
| `deviceName` | 否 | 设备名称,首次上报自动建档时使用 |
| `deviceType` | 否 | 设备类型:`MOSQUITO_TRAP`=智能捕蚊器 / `DENSITY_MONITOR`=密度监测仪 / `SENSOR`=传感器 |
| `siteId` | 否 | 关联孳生地ID(孳生地在 Web"蚊媒孳生地"Tab 创建,ID 即列表主键) |
| `siteName` | 否 | 孳生地名称(便于台账/明细展示) |
| `metricType` | 否 | 指标类型,见 §3,默认 `DENSITY` |
| `threshold` | 否 | 预警阈值,不传按指标默认阈值(见 §3) |
| `collectedAt` | 否 | 采集时间,格式 `yyyy-MM-dd HH:mm:ss` 或 ISO 格式,东八区;不传默认当前时间;离线补传请传实际采集时间 |

请求示例:

```json
{
  "deviceNo": "MD-DEVICE-0001",
  "deviceName": "康怡花园智能捕蚊器",
  "deviceType": "MOSQUITO_TRAP",
  "siteId": 1,
  "siteName": "康怡花园3栋后积水沟渠",
  "metricType": "DENSITY",
  "metricValue": 12.5,
  "threshold": 10,
  "collectedAt": "2026-08-13 10:00:00"
}
```

### 2.3 响应

```json
{
  "code": 200,
  "success": true,
  "message": "OK",
  "data": {
    "success": true,
    "alarmLevel": "OVER",
    "collectedAt": "2026-08-13T10:00"
  }
}
```

| code | 含义 | 说明 |
|---|---|---|
| `200` | 接收成功 | `alarmLevel` 为平台超标判定结果:`OVER`=超标 / `NORMAL`=正常,设备侧可据此做本地告警 |
| `400` | 参数不合法 | `message` 返回具体原因(如缺少 deviceNo / metricValue、指标类型不支持) |
| `500` | 服务器错误 | 数据入库失败,可稍后重试 |

## 3. 指标类型与默认阈值

| metricType | 指标 | 默认阈值 |
|---|---|---|
| `DENSITY` | 成蚊密度(只/灯·夜) | 10 |
| `CAPTURE` | 捕获数(只) | 50 |
| `BITE` | 叮咬率(次/人·夜) | 5 |
| `BREEDING` | 孳生指数 | 30 |

一台设备可同时推送多种指标,各自独立判定;`threshold` 字段可覆盖默认值。

## 4. 平台自动处理(设备侧无需关心)

1. **自动注册**:`deviceNo` 不存在时自动创建设备台账(名称、类型、关联孳生地、在线状态)
2. **超标判定**:`metricValue > threshold` → `OVER`,Web 趋势图该数据点标红
3. **去重**:同一设备 + 同一指标 + 同一采集时间只保留一条,重复推送不产生脏数据
4. **在线状态**:每次上报将设备置为 `ONLINE` 并刷新最后上报时间,台账实时展示

## 5. 设备侧落地方式(任选)

| 方式 | 说明 |
|---|---|
| 直连上报 | 设备/固件支持 HTTP,定时 POST(建议 5~30 分钟一条) |
| DTU/网关转发 | 4G/NB-IoT DTU 采集传感器数据,按本协议转发 |
| 厂家平台转发 | 设备厂家平台配置 Webhook,回调转发到本接口(与无人机 AI 告警接入同模式) |
| 边缘盒子脚本 | 工控机/树莓派运行定时脚本(见 §6.2 Python 示例) |

## 6. 联调示例

### 6.1 curl 快速验证

```bash
curl -k -X POST https://drone.kfktec.cn:8443/api/integrations/mosquito/device-data \
  -H 'Content-Type: application/json' \
  -d '{"deviceNo":"MD-TEST-DEMO","deviceName":"联调测试设备","siteId":1,"siteName":"康怡花园3栋后积水沟渠","metricType":"DENSITY","metricValue":12.5,"collectedAt":"2026-08-13 10:00:00"}'
```

### 6.2 Python 定时上报(边缘盒子参考)

```python
import json
import time
import random
import urllib.request

API = "https://drone.kfktec.cn:8443/api/integrations/mosquito/device-data"
DEVICE = {"deviceNo": "MD-DEVICE-0001", "deviceName": "康怡花园智能捕蚊器",
          "siteId": 1, "siteName": "康怡花园3栋后积水沟渠"}

def report(metric_type, value):
    body = json.dumps({**DEVICE, "metricType": metric_type,
                       "metricValue": round(value, 2)}).encode()
    req = urllib.request.Request(API, body, {"Content-Type": "application/json"}, method="POST")
    with urllib.request.urlopen(req) as resp:
        print(resp.read().decode())

while True:
    report("DENSITY", random.uniform(3, 13))   # 实际替换为传感器读数
    time.sleep(1800)                            # 每 30 分钟一条
```

## 7. 数据管理与注意事项

- **模拟数据区分**:演示数据时间戳为严格整点规律(每 2 小时),设备备注"自动注册演示设备";真实数据无此规律
- **清理模拟数据**:真实设备接入后建议清理,需清理时联系平台运维执行 SQL(仅清理 `biz_mosquito_device_data` / `biz_mosquito_device` 中备注为演示/整点规律的数据)
- **时间**:统一东八区;设备离线补传时 `collectedAt` 传实际采集时间,平台按时间去重排序
- **生产安全**:当前推送接口公开(设备无账号)。正式生产若需防伪造,可参照平台 `ThirdPartyCallbackVerifier`(HMAC-SHA256 签名)增加校验,由平台侧改造

## 8. 平台管理查询接口(Web 端使用,需登录令牌)

| 接口 | 说明 |
|---|---|
| `GET /api/community/mosquito/devices?page=&size=` | 设备台账列表(含最新指标/数值/上报时间) |
| `GET /api/community/mosquito/device-data?siteId=&deviceNo=&metricType=&page=&size=` | 监测数据明细 |
| `GET /api/community/mosquito/device-data/trend?siteId=&metricType=&hours=` | 趋势点(供图表) |
| `GET /api/community/mosquito/device-data/statistics` | 统计(设备数/在线/今日上报/近7日超标) |
| `POST /api/community/mosquito/device-data/simulate` | 一键生成演示数据 `{"days": 3}`(演示期使用,接入真实设备后停用) |
