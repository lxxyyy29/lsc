# 网格社区治理平台 — 系统说明文档

## 一、项目概述

### 1.1 项目定位

网格社区治理平台是一个面向基层社区治理的综合性信息化平台，实现"发现上报→智能派单→现场处置→复核核查→督办预警→归档"全流程闭环管理，支持三色分级（绿/黄/红）和超期自动升级。

### 1.2 四大应用端

| 应用 | 目录 | 开发端口 | 用途 |
|------|------|------|------|
| 后端 API | `backend/` | 8080 | Spring Boot 3.3 REST API，context-path: `/api` |
| Web 管理端 | `web/` | 5175 | Vue 3 + TypeScript + Element Plus，管理人员使用 |
| H5 移动端 | `h5/` | 5174 | Vue 3 + uni-app + Vant，网格员现场处置使用 |
| 小程序（居民端） | `mp/` | 5176 | Vue 3 + Vite，居民随手拍上报、查询、评价 |

生产环境通过 `docker/` 目录的 docker-compose 部署，对外端口：后端 `10081`、Web `8888`、H5 `10082`、小程序 `10083`（可在 `docker/.env` 中调整）。

### 1.3 技术栈

| 层级 | 技术 |
|------|------|
| 后端框架 | Spring Boot 3.3 / Java 17 |
| 数据库 | MySQL 8.0（业务数据，生产镜像 mysql:8.0） |

| 文档数据库 | MongoDB 6.0（告警事件） |

## 三、核心业务流程

### 3.1 事件闭环处置流程（R11）

```
发现上报 → 智能派单 → 审核审批 → 现场处置 → 复核核查 → 归档/驳回
```

**状态机：**

```
事件状态:
  WAITING_DISPATCH → PENDING_AUDIT → IN_AUDIT → DISPATCHED_TO_WORK_ORDER → CLOSED / IGNORED / ARCHIVED

工单状态:
  WAITING_ACCEPT → PROCESSING → WAITING_VERIFY → WAITING_CLOSE_CONFIRM → COMPLETED / CLOSED / TIMEOUT

紧急程度三色:
  GREEN（绿）→ 超过24h自动升级 → YELLOW（黄）→ 超过48h自动升级 → RED（红）
```

**处置结果分支（5种）：**
- `RESOLVED` — 属实并已处理 → 进入复核
- `CONTINUE_PROCESSING` — 属实但需继续处理 → 进入复核
- `NOT_TRUE` — 不属实 → 事件关闭
- `NEEDS_MORE_EVIDENCE` — 需补充证据 → 退回补充
- `APPROVED/REJECTED` — 审核通过/驳回

### 3.2 网格巡查流程（R09）

```
每周一凌晨定时生成周任务（也可手动生成）→ 网格员领取 → 现场巡查打卡 → 上报问题/记录
    → 完成任务 → 每日凌晨自动标记超期（也可手动标记）
```

### 3.3 工单处理流程

```
派发工单 → H5接单(H5) → 到场(H5) → 处理(H5) → 提交结果(H5)
    → Web复核 → 确认关闭(Web) / 驳回(Web)
```

### 3.4 居民注册流程

```
小程序提交注册（POST /registration/submit）→ 管理员审核
    → 通过（/registration/{id}/approve）/ 驳回（/registration/{id}/reject）
```

> 上传文件自 V80 起采用**扁平存储**（直接存放于 uploads 根目录），访问 URL 前缀由 `docker/.env` 的 `DOMAIN` 拼接（当前为 HTTPS 域名，如 `https://drone.kfktec.cn:8443/media/files/{filename}`；开发环境为 `http://{host}:8888/media/files/{filename}`）。此前按 `yyyy/MM/dd` 日期子目录存储的文件会被 Spring 6 的日期路径防护拦截（404），故新增专用读取接口向下遍历兼容存量文件。

> **定位说明**：全站为 HTTP+IP 访问，浏览器禁止非 HTTPS 页面使用精确定位，因此 mp/h5/web 三端定位均采用 `navigator.geolocation` 失败后回退**高德 JS API CitySearch IP 定位**（城市级）。如需精确 GPS 定位需配置域名+HTTPS 证书。

## 八、认证与权限模型

### 8.1 认证方式

- **Web 端 / 小程序**：`POST /auth/login` → 返回 JWT → 后续请求 `Authorization: Bearer <token>`
- **H5 端**：`POST /h5/auth/login` → 返回 JWT
- Token 有效期：7 天（可配置）

### 8.2 权限体系

采用 RBAC 模型：
- **用户** (sys_user) → **角色** (sys_role) → **权限** (sys_permission)
- 权限分为两类：
  - `API_*` — 接口访问权限（后端校验）
  - `MENU_*` / `menu:*` — 菜单显示权限（前端控制导航）
- Web 与 H5 是独立的客户端权限面（clientType 区分）

### 8.3 关键权限码（节选）

| 权限码 | 说明 |
|--------|------|
| `API_AUTH_WEB_ME` | 获取当前用户信息 |
| `API_EVENT_CREATE` / `API_EVENT_DETAIL` / `API_EVENT_LIST` | 事件创建/详情/列表 |
| `API_EVENT_IGNORE` / `API_EVENT_CLOSE` | 标记误报 / 关闭事件 |
| `API_WORKORDER_DISPATCH` / `API_WORKORDER_HANDLE` | 派发 / 处理工单 |
| `API_WORKORDER_CONFIRM_CLOSE` | 确认/驳回关闭 |
| `API_AUDIT_START` / `API_AUDIT_DETAIL` | 发起审核 / 查看审核 |
| `API_PROCESS_INSTANCE_APPROVE` / `API_PROCESS_INSTANCE_REJECT` | 审批通过 / 驳回 |
| `API_PROCESS_TEMPLATE_*` | 流程模板 CRUD |
| `API_SYSTEM_USER_*` / `API_SYSTEM_ROLE_*` | 用户/角色管理 |
| `API_SYSTEM_PERMISSION_LIST` / `API_SYSTEM_MENU_*` | 权限/菜单管理 |
| `API_INTEGRATION_VIEW` / `API_INTEGRATION_MANAGE` | 信息互通查看/管理 |
| `API_H5_MERCHANT_*` / `API_H5_VENDOR_*` | H5 商户/摊贩管理 |
| `MENU_INTEGRATION_VIEW` | 信息互通菜单显示 |

> 完整权限清单以数据库 `sys_permission` 表和 Flyway 迁移脚本为准。

生产环境使用 `docker/` 目录下的 docker-compose 一键部署（详见 `docs/部署实操指南.md`）：

| 容器 | 对外端口 | 说明 |
|------|---------|------|
| `changping-backend` | 10081 → 8080 | 后端 API |
| `changping-web` | 8888 → 80 | Web 管理端（nginx） |
| `changping-h5` | 10082 → 80 | H5 移动端（nginx） |
| `changping-mp` | 10083 → 80 | 小程序（nginx） |
| `changping-mysql` / `changping-redis` / `changping-mongodb` / `changping-minio` | 仅内网 | 依赖服务（MySQL 实际为 8.0） |

端口和密码在 `docker/.env` 中配置（`WEB_PORT`、`BACKEND_PORT`、`H5_PORT`、`MP_PORT`、`MYSQL_ROOT_PASSWORD` 等）。

此外 changping-web 的 nginx 还提供 **HTTPS 聚合入口 `${HTTPS_PORT:-8443}→443`**（域名见 `docker/.env` 的 `DOMAIN`，当前 `https://drone.kfktec.cn:8443`），同时代理 `/h5/`、`/mp/` 子入口；浏览器精确定位仅 HTTPS 可用，故定位类功能需走 8443 入口。

### 10.4 配置项

所有敏感配置通过环境变量注入，fallback 默认值在 `application.yml` 中：
- `DB_URL` / `DB_USERNAME` / `DB_PASSWORD` — 数据库连接
- `MONGODB_HOST` / `MONGODB_PORT` — MongoDB 连接
- `REDIS_HOST` / `REDIS_PASSWORD` / `REDIS_DATABASE` — Redis 连接
- `JWT_SECRET` — JWT 签名密钥
- `OSS_ENDPOINT` / `OSS_ACCESS_KEY` / `OSS_SECRET_KEY` — MinIO 配置
- `DRONE_API_SERVER` / `DRONE_API_USERNAME` / `DRONE_API_PASSWORD` — 无人机平台
- `APP_TEST_ENABLED` — 是否启用测试接口（默认 false，生产环境务必不设置）
