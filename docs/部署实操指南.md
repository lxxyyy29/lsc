# 网格社区治理平台 — 阿里云部署实操指南

> 适用环境：阿里云 ECS（CentOS/Ubuntu）
> 目标：使用 Docker Compose 一键部署后端 + Web + H5 + 小程序
> 最后更新：2026-08-05（按实际部署状态核对：项目路径 /opt/zhsq/repo，Web 端口 8888）

---

## 一、部署前准备

### 1.1 确认服务器环境

通过 XShell 连接到服务器后，执行以下命令确认环境：

```bash
# 查看系统版本
cat /etc/os-release

# 查看磁盘空间（确保至少有 20GB 可用）
df -h

# 查看内存（建议 4GB 以上）
free -h

# 查看 Docker 是否已安装
docker --version
docker compose version || docker-compose --version
```

### 1.2 确认端口空闲

```bash
# 检查我们将要使用的端口是否被占用
ss -tlnp | grep -E '8888|10081|10082|10083'
```

**预期结果**：无输出（表示端口空闲）

如果端口被占用，可以在 `.env` 文件中修改为其他空闲端口。

### 1.3 配置阿里云安全组

在阿里云控制台 → ECS 实例 → 安全组 → 添加规则：

| 端口范围 | 协议 | 来源 | 说明 |
|---------|------|------|------|
| 8888 | TCP | 0.0.0.0/0 | Web 管理端 HTTP |
| 10081 | TCP | 你的IP/32 | 后端 API（建议限制 IP） |
| 10082 | TCP | 0.0.0.0/0 | H5 移动端 |
| 10083 | TCP | 0.0.0.0/0 | 小程序 |

> ⚠️ 10081 后端端口建议只开放给你的办公 IP，避免 API 被公网直接访问。

## 二、安装 Docker（如已安装可跳过）

### 2.1 安装 Docker Engine

```bash
# 卸载旧版本（如有）
sudo yum remove docker docker-client docker-client-latest docker-common docker-latest docker-latest-logrotate docker-logrotate docker-engine 2>/dev/null || true

# 安装依赖
sudo yum install -y yum-utils device-mapper-persistent-data lvm2

# 添加 Docker 仓库
sudo yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo

# 安装 Docker
sudo yum install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

# 启动 Docker
sudo systemctl enable docker
sudo systemctl start docker

# 验证安装
docker --version
```

### 2.2 安装 Docker Compose（独立版）

```bash
# 下载 Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/download/v2.20.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose

# 添加执行权限
sudo chmod +x /usr/local/bin/docker-compose

# 创建软链接
sudo ln -sf /usr/local/bin/docker-compose /usr/bin/docker-compose

# 验证安装
docker-compose --version
```

### 2.3 配置 Docker 镜像加速（推荐）

```bash
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors": [
    "https://docker.1ms.run",
    "https://docker.xuanyuan.me"
  ],
  "log-driver": "json-file",
  "log-opts": {
    "max-size": "100m",
    "max-file": "3"
  }
}
EOF

sudo systemctl daemon-reload
sudo systemctl restart docker
```

## 四、配置环境变量

### 4.1 创建 .env 文件

```bash
cd /opt/zhsq/repo/docker
cp .env.example .env
```

### 4.2 编辑 .env 文件

```bash
vim .env
```

**内容说明**：

```bash
# ============================================
# 端口配置（当前生产实际值，可按需调整）
# ============================================
WEB_PORT=8888         # Web 管理端对外端口
H5_PORT=10082         # H5 移动端对外端口
MP_PORT=10083         # 小程序对外端口
BACKEND_PORT=10081    # 后端 API 对外端口

# ============================================
# MySQL 配置
# ============================================
MYSQL_ROOT_PASSWORD=你的强密码这里    # ⚠️ 必须修改！

# ============================================
# Redis 配置
# ============================================
REDIS_PASSWORD=你的强密码这里          # ⚠️ 必须修改！

# ============================================
# MinIO 对象存储
# ============================================
MINIO_USER=admin
MINIO_PASSWORD=你的强密码这里          # ⚠️ 必须修改！

# ============================================
# JWT 密钥（用于生成登录令牌）
# ============================================
JWT_SECRET=这里填入至少32位随机字符串   # ⚠️ 必须修改！

# ============================================
# 访问域名（用于生成文件下载链接）
# ============================================
DOMAIN=http://8.156.93.151:8888
```

### 4.3 生成随机密码（推荐）

如果不确定用什么密码，可以用命令生成随机密码：

```bash
# 生成 24 位随机密码
openssl rand -base64 24 | tr -dc 'a-zA-Z0-9!@#$%^&*' | head -c 24
echo ""

# 生成 48 位 JWT 密钥
openssl rand -base64 48 | tr -dc 'a-zA-Z0-9' | head -c 48
echo ""
```

## 五、构建并启动服务

### 5.1 构建镜像

```bash
cd /opt/zhsq/repo/docker

# 构建所有服务镜像（首次需要 5-10 分钟）
docker-compose build --no-cache
```

**构建过程说明**：
1. `changping-backend` — 基于 Maven 打包 Spring Boot JAR
2. `changping-web` — 基于 Vite 构建 Vue 3 前端
3. `changping-h5` — 基于 Vite 构建 uni-app H5
4. `changping-mp` — 基于 Vite 构建小程序

### 5.2 启动服务

```bash
# 启动所有服务（后台运行）
docker-compose up -d
```

### 5.3 查看启动状态

```bash
# 查看所有容器状态
docker-compose ps

# 查看实时日志
docker-compose logs -f

# 查看特定服务日志
docker-compose logs -f changping-backend
```

**预期输出**：
```
NAME                    STATUS                  PORTS
changping-mysql         Up 4 seconds (healthy)
changping-redis         Up 4 seconds (healthy)
changping-mongodb       Up 4 seconds (healthy)
changping-minio         Up 4 seconds (healthy)
changping-backend       Up 3 seconds           0.0.0.0:10081->8080/tcp
changping-web           Up 2 seconds           0.0.0.0:8888->80/tcp
changping-h5            Up 2 seconds           0.0.0.0:10082->80/tcp
changping-mp            Up 2 seconds           0.0.0.0:10083->80/tcp
```

> ✅ 已修复（2026-08-05）：changping-backend 曾因 Dockerfile 的 healthcheck 用虚构账号
> `health/check` 调登录接口必然失败而持续显示 `unhealthy` 误报。现已改为 HTTP 连通性探测
> （任何 HTTP 响应即视为存活），容器状态恢复正常。

### 5.4 等待服务就绪

```bash
# 检查后端 API 是否就绪
curl -s http://localhost:10081/api/auth/login \
  -X POST \
  -H "Content-Type: application/json" \
  -d '{"account":"health","password":"check"}'
```

**预期响应**：`{"success":false,...}` 或 `{"success":true,...}`（表示服务已启动）

## 九、安全加固建议

### 9.1 必须做的

1. **修改默认密码** — `.env` 中所有密码
2. **配置安全组** — 仅开放必要端口
3. **不要提交 .env 到 Git** — 已在 .gitignore 中

### 9.2 推荐做的

1. **配置 HTTPS** — 使用 Nginx 反向代理 + SSL 证书
2. **限制 API 访问** — 10081 端口只开放给办公 IP
3. **定期备份** — 设置定时任务备份数据库
4. **日志监控** — 配置日志轮转和监控告警

### 9.3 HTTPS 配置（可选）

如果需要配置 HTTPS，可以在服务器上添加 Nginx 反向代理：

```nginx
# /etc/nginx/conf.d/changping.conf
server {
    listen 443 ssl;
    server_name your-domain.com;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    location / {
        proxy_pass http://127.0.0.1:8888;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:10081;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 十、常见问题

### 10.1 端口冲突

**问题**：启动时报错 `port is already allocated`

**解决**：修改 `.env` 文件中的端口映射：
```bash
WEB_PORT=20080  # 改为其他空闲端口
```

### 10.2 容器启动失败

**问题**：`docker-compose up -d` 后容器反复重启

**解决**：
```bash
# 查看日志找到错误原因
docker-compose logs changping-backend

# 常见原因：
# 1. 端口被占用 → 修改端口
# 2. 内存不足 → 增加服务器内存或限制容器内存
# 3. 配置错误 → 检查 .env 文件
```

### 10.3 无法访问

**问题**：浏览器无法打开页面

**解决**：
```bash
# 1. 检查容器是否运行
docker-compose ps

# 2. 检查服务是否正常
curl http://localhost:8888

# 3. 检查阿里云安全组是否开放端口

# 4. 检查服务器防火墙
sudo systemctl status firewalld
sudo firewall-cmd --list-ports
```

### 10.4 数据库迁移

**问题**：首次启动时 Flyway 迁移失败

**解决**：
```bash
# 查看后端日志
docker-compose logs changping-backend | grep -i flyway

# 如果迁移失败，可以重置数据库
docker-compose down
sudo rm -rf /home/docker/uav/changping/data/mysql/*
docker-compose up -d
```
