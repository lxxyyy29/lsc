## 二、P4-1 综合监管大屏

### 2.1 目标

创建一个独立的大屏页面，展示平台核心数据：
- 事件总数/今日新增/待处理/已处置
- 各网格事件分布柱状图
- 事件类型饼图
- 近 7/30 天趋势折线图
- 实时工单滚动列表
- 网格员处置排行榜

### 2.2 后端接口

| 接口 | 说明 |
|------|------|
| `GET /api/dashboard/big-screen` | 大屏汇总数据（一次性返回所有指标） |

### 2.3 数据来源

基于现有表聚合查询：
- `biz_event` — 事件统计
- `biz_work_order` — 工单统计
- `cmn_grid` — 网格维度
- `cmn_patrol_record` — 巡查数据

### 2.4 前端

- `BigScreenView.vue` — 深色背景大屏页面
- 使用 CSS Grid/Flexbox 布局
- 纯 CSS 图表（柱状图、饼图、折线图）避免额外依赖
- 自动刷新（每 60 秒）

---

## 三、P4-2 移动端 GIS

### 3.1 目标

在 H5 端增加地图能力：
- 查看周边事件
- 实时位置上报
- 轨迹记录

### 3.2 后端

复用现有接口：
- `GET /api/events/map-points` — 地图点位
- `POST /api/community/patrol-records` — 巡查记录上报

新增：
- `GET /api/h5/map/nearby-events` — 周边事件查询

### 3.3 前端

- `h5/src/views/MapView.vue` — H5 地图页面
- 使用 AMap 定位 API
- 事件标记 + 信息窗体
