# 性能优化计划

> 生成时间：2026-07-31

---

## 一、SQL 优化

### 1.1 添加缺失索引
- `biz_event.record_id` — 事件记录查询
- `biz_event_record.event_id + created_at` — 事件历史查询
- `sys_audit_log.operation_time` — 审计日志时间范围查询
- `biz_work_order.status + created_at` — 工单状态筛选

### 1.2 慢查询优化
- 大屏数据接口合并多次查询为一次
- 减少 N+1 查询

---

## 二、缓存策略

### 2.1 菜单/权限缓存
- 用户登录后缓存权限信息到 Redis
- 减少每次请求的权限查询

### 2.2 基础数据缓存
- 网格列表、字典数据等低频变更数据缓存

---

## 三、前端优化

### 3.1 路由懒加载
- 确保所有页面组件使用 `() => import(...)` 懒加载

### 3.2 接口响应优化
- 大数据量接口增加分页
- 减少不必要的数据返回

---

## 实施顺序

1. SQL 索引优化（立竿见影）
2. 前端路由懒加载检查
3. 缓存策略（需要 Redis 环境）
