## 二、快速部署（本地开发）

### 1. 获取项目代码

项目位于服务器 `/opt/zhsq/repo`（git 远程：`https://github.com/lxxyyy29/lsc.git`）。

```bash
cd /opt/zhsq/repo
```

### 2. 配置环境变量

创建 `.env` 文件：

```env
# 数据库
DB_URL=jdbc:mysql://127.0.0.1:3306/zhsq?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
DB_USERNAME=root
DB_PASSWORD=your_password

# MongoDB
MONGODB_HOST=127.0.0.1
MONGODB_PORT=27017
MONGODB_DATABASE=alarm_dgcp

# Redis
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_PASSWORD=your_password
REDIS_DATABASE=7

# JWT
JWT_SECRET=your-secret-key-here

# MinIO
OSS_ENDPOINT=http://127.0.0.1:9009/
OSS_ACCESS_KEY=admin
OSS_SECRET_KEY=your_minio_secret
OSS_BUCKET=dgcp-oa

# 安全
APP_TEST_ENABLED=false
```

### 3. 启动依赖服务

以下为 Windows 示例；Linux 服务器实际采用 Docker 容器（changping-mysql/redis/mongodb/minio），见下文生产部署。

```bash
# MySQL（Windows）
net start MySQL

# MongoDB
net start MongoDB

# Redis
redis-server

# MinIO
minio server C:\minio-data --console-address ":9001"
```

### 4. 启动后端

```bash
cd backend
./mvnw spring-boot:run
```

### 5. 启动前端

```bash
# Web 管理端
cd web
npx pnpm install
npx pnpm dev --host 0.0.0.0 --port 5175

# H5 移动端
cd h5
npx pnpm install
npx pnpm dev --host 0.0.0.0 --port 5174

# 小程序
cd mp
npx pnpm install
npx pnpm dev --host 0.0.0.0 --port 5176
```

## 三、生产部署

生产环境实际采用 `docker/` 目录的 docker-compose 一键部署（详见 `docs/部署实操指南.md`），容器与端口：

| 容器 | 对外端口 |
|------|---------|
| changping-backend | 10081 |
| changping-web | 8888 |
| changping-h5 | 10082 |
| changping-mp | 10083 |

数据持久化在宿主机 `/home/docker/uav/changping/data/` 与 `/home/docker/uav/changping/uploads/`。

以下为不用 Docker 时的手动打包方式（仅供参考）：

### 后端打包

```bash
cd backend
./mvnw clean package -DskipTests
java -jar target/platform-0.0.1-SNAPSHOT.jar
```

### 前端打包

```bash
# Web 管理端
cd web
npx pnpm build
# 产物在 dist/ 目录，部署到 Nginx

# H5 移动端
cd h5
npx pnpm build

# 小程序
cd mp
npx pnpm build
```

### Nginx 配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # Web 管理端
    location / {
        root /var/www/web/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # API 代理
    location /api/ {
        proxy_pass http://localhost:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # 媒体文件
    location /media/ {
        proxy_pass http://localhost:8080/media/;
    }
}
```

## 五、常见问题

### 1. 端口占用

```bash
# Linux：查找占用端口的进程
ss -tlnp | grep :8080

# Windows：
netstat -ano | findstr :8080
taskkill //F //PID <PID>
```

### 2. MongoDB 连接失败

检查 MongoDB 是否启动：
```bash
mongosh --eval "db.version()"
```

### 3. 文件上传失败

检查 MinIO 是否运行，bucket 是否存在：
```bash
mc alias set local http://127.0.0.1:9009 admin password
mc mb local/dgcp-oa
```

### 4. 测试接口暴露

确保生产环境 `APP_TEST_ENABLED` 未设置或设为 `false`。

## 七、备份与恢复

### 数据库备份

```bash
# MySQL
mysqldump -u root -p zhsq > backup_zhsq.sql

# MongoDB
mongodump --db alarm_dgcp --out /backup/mongodb
```

### 数据库恢复

```bash
# MySQL
mysql -u root -p zhsq < backup_zhsq.sql

# MongoDB
mongorestore --db alarm_dgcp /backup/mongodb/alarm_dgcp
```

## 八、安全建议

1. **修改默认密码**：首次登录后立即修改 admin 密码
2. **JWT 密钥**：生产环境使用随机生成的强密钥
3. **HTTPS**：生产环境必须启用 HTTPS
4. **防火墙**：仅开放必要端口
5. **定期备份**：设置定时备份任务
6. **日志审计**：定期检查操作日志
