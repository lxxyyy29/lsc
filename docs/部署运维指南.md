# 网格社区治理平台 — 部署运维指南

## 一、环境要求

### 服务端

| 组件 | 最低版本 | 推荐版本 | 说明 |
|------|---------|---------|------|
| JDK | 17 | 17.0.9+ | 必须 Java 17 |
| Maven | 3.8+ | 3.9+ | 或使用 mvnw |
| MySQL | 8.0 | 9.7 | 业务数据库 |
| MongoDB | 5.0 | 6.0 | 告警事件存储 |
| Redis | 6.0 | 7.0 | 会话/令牌缓存 |
| MinIO | latest | latest | 文件对象存储 |

### 客户端

| 组件 | 版本 | 说明 |
|------|------|------|
| Node.js | 18+ | 前端构建 |
| pnpm | 8+ | 包管理器 |

## 二、快速部署

### 1. 克隆项目

```bash
git clone https://github.com/lxxyyy29/lsc.git
cd lsc
```

### 2. 配置环境变量

创建 `.env` 文件：

```env
# 数据库
DB_URL=jdbc:mysql://127.0.0.1:3306/zhsq?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
DB_USERNAME=root
DB_PASSWORD=your_password

# MongoDB
MONGODB_HOST=127.0.0.1
MONGODB_PORT=27017
MONGODB_DATABASE=alarm_dgcp

# Redis
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_PASSWORD=your_password
REDIS_DATABASE=7

# JWT
JWT_SECRET=your-secret-key-here

# MinIO
OSS_ENDPOINT=http://127.0.0.1:9009/
OSS_ACCESS_KEY=admin
OSS_SECRET_KEY=your_minio_secret
OSS_BUCKET=dgcp-oa

# 安全
APP_TEST_ENABLED=false
```

### 3. 启动依赖服务

```bash
# MySQL
net start MySQL

# MongoDB
net start MongoDB

# Redis
redis-server

# MinIO
minio server C:\minio-data --console-address ":9001"
```

### 4. 启动后端

```bash
cd backend
./mvnw spring-boot:run
```

### 5. 启动前端

```bash
# Web 管理端
cd web-v2
npx pnpm install
npx pnpm dev --host 0.0.0.0 --port 5175

# H5 移动端
cd h5
npx pnpm install
npx pnpm dev --host 0.0.0.0 --port 5174

# 小程序
cd mp_mysql_test
npx pnpm install
npx pnpm dev --host 0.0.0.0 --port 5176
```

## 三、生产部署

### 后端打包

```bash
cd backend
./mvnw clean package -DskipTests
java -jar target/platform-0.0.1-SNAPSHOT.jar
```

### 前端打包

```bash
# Web 管理端
cd web-v2
npx pnpm build
# 产物在 dist/ 目录，部署到 Nginx

# H5 移动端
cd h5
npx pnpm build

# 小程序
cd mp_mysql_test
npx pnpm build
```

### Nginx 配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # Web 管理端
    location / {
        root /var/www/web-v2/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # API 代理
    location /api/ {
        proxy_pass http://localhost:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # 媒体文件
    location /media/ {
        proxy_pass http://localhost:8080/media/;
    }
}
```

## 五、常见问题

### 1. 端口占用

```bash
# 查找占用端口的进程
netstat -ano | findstr :8080

# 结束进程
taskkill //F //PID <PID>
```

### 2. MongoDB 连接失败

检查 MongoDB 是否启动：
```bash
mongosh --eval "db.version()"
```

### 3. 文件上传失败

检查 MinIO 是否运行，bucket 是否存在：
```bash
mc alias set local http://127.0.0.1:9009 admin password
mc mb local/dgcp-oa
```

### 4. 测试接口暴露

确保生产环境 `APP_TEST_ENABLED` 未设置或设为 `false`。

## 七、备份与恢复

### 数据库备份

```bash
# MySQL
mysqldump -u root -p zhsq > backup_zhsq.sql

# MongoDB
mongodump --db alarm_dgcp --out /backup/mongodb
```

### 数据库恢复

```bash
# MySQL
mysql -u root -p zhsq < backup_zhsq.sql

# MongoDB
mongorestore --db alarm_dgcp /backup/mongodb/alarm_dgcp
```

## 八、安全建议

1. **修改默认密码**：首次登录后立即修改 admin 密码
2. **JWT 密钥**：生产环境使用随机生成的强密钥
3. **HTTPS**：生产环境必须启用 HTTPS
4. **防火墙**：仅开放必要端口
5. **定期备份**：设置定时备份任务
6. **日志审计**：定期检查操作日志
