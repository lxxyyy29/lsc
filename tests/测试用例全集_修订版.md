## 附录 D：核心业务流程状态机

### 事件状态机
```
事件接入 → PENDING_AUDIT（待审核）→ IN_AUDIT（审核中）→ AUDIT_APPROVED（审核通过）
                                                              ↓ 派单
                                            WAITING_DISPATCH（待派单）→ DISPATCHED_TO_WORK_ORDER（已派工单）→ CLOSED（已关闭）
                                                              ↑
                                              （有组长时审核通过先进入 WAITING_LEADER_REVIEW 组长审核，再进入待派单）
驳回分支：PENDING_AUDIT / IN_AUDIT → AUDIT_REJECTED（已驳回，允许重新提交审核回到 PENDING_AUDIT）
独立终态：IGNORED（误报标记） / ARCHIVED（归档）
```

### 工单状态机
```
WAITING_ACCEPT（待接单）→ PROCESSING（处理中）→ WAITING_VERIFY（待核实）→ WAITING_CLOSE_CONFIRM（待关闭确认）→ COMPLETED（已完成）
                      ↓                                                                              ↓
                NEEDS_MORE_EVIDENCE（需补充证据）→ PROCESSING（退回继续处理）                          CLOSED（已关闭）
TIMEOUT（超时未接单自动关闭，终态）
```

### 紧急程度三色升级
```
GREEN（绿）→ 超过 24h → YELLOW（黄）→ 超过 48h → RED（红）
```
